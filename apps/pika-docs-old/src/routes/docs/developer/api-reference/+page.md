## Overview

The Pika Framework provides several APIs for managing chat applications, users, and administrative functions. This reference will cover:

- **Chat APIs** - Core chat functionality and message handling
- **User Management APIs** - User authentication and profile management
- **Admin APIs** - Administrative functions and site management
- **Override APIs** - Chat app access control and configuration overrides
